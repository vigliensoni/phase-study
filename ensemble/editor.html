Each sound gets a name (used in the events below) and is saved as audio/<file> in the piece's folder. Sounds loop, unless the event that plays them ticks Play once. Prefer .mp3 or .ogg, and keep each file under 100 MB.

Events

Play starts a sound in the chosen groups (Play once plays the file once instead of looping; Fade out end fades over its last seconds), stop fades it out. Ratio drifts the phones of a group apart; spread drifts the groups apart (the whole piece). Level changes loudness; set changes an effect setting. Fades and glides are in seconds.
